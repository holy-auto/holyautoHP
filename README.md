# HOLY AUTO ホームページ

輸入車・高級車のコーティングと電装取付の専門店「HOLY AUTO（株式会社HOLY）」の公式サイトです。
旧 Wix サイトの内容をベースに、デザインと導線を作り直しました。ビルド不要の静的サイトなので、
GitHub Pages・Netlify・Cloudflare Pages などにそのまま置けます。

> 旧 Wix サイトをそのまま再現した版は、コミット `a0be0c3` に残っています。

## ページ構成

| ファイル | 内容 |
| --- | --- |
| `index.html` | ホーム（ヒーロー / 認定・実績 / サービス / 選ばれる理由 / プラン / 施工事例 / 流れ / 口コミ / 業者様 / お知らせ / アクセス） |
| `coating.html` | コーティング（悩み / 4ブランド比較表 / プラン / 施工工程 / FAQ） |
| `electronics.html` | 電装・カスタム（取付メニュー / 相談時に送るもの / FAQ） |
| `brands.html` | 取扱ブランド（カーケア / カスタム・電装） |
| `blog.html` | お知らせ・施工事例 |
| `assets/css/style.css` | 共通スタイル（色・余白は冒頭の `:root` で一括管理） |
| `assets/js/main.js` | 外部リンク設定・メニュー |

## 公開前に必要な対応

1. **外部リンク**：`assets/js/main.js` 冒頭の `LINKS` に URL を入れる
   - `book`（Square 予約） / `line`（公式LINE） / `x` / `instagram` / `mitsumoa`
2. **料金**：プランカードの `¥XX,XXX`（金色の仮表記）を実際の価格に差し替える（`index.html` と `coating.html`）
3. **写真**：施工事例の「施工写真を追加」枠、記事写真の枠を実際の写真に差し替える
   - 現在の写真2枚は旧サイトのスクリーンショットから切り出した低解像度の仮画像です
   - ロゴも元データ（背景透過のPNG/SVG）があれば差し替えると綺麗になります
4. **ドメイン決定後**：`<link rel="canonical">`・OGP画像の絶対URL・`sitemap.xml` を追加する
